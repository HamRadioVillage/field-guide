# FUNDAMENTAL FORMULAS
## CORE
- λ (meters) = 300 / f (MHz)
- Quarter wave ≈ 75 / f (MHz)
- Half wave ≈ 150 / f (MHz)
## POWER / dB
- dB = 10·log10(P2/P1)
- +3 dB ≈ 2× power
- +10 dB ≈ 10× power
- -3 dB ≈ 1/2 power
## RANGE (ROUGH)
- Range ∝ √Power
  → 4× power ≈ 2× range
# RADIO PERFORMANCE — ORDER OF IMPORTANCE
1. Line of sight  
2. Elevation (antenna height)  
3. Obstructions (terrain, buildings, body)  
4. Antenna quality / tuning / orientation  
5. Frequency (propagation characteristics)  
6. Distance  
7. Environment (foliage, weather, RF noise)  
8. Feedline loss (coax, connectors)  
9. Power (watts)

---
## OBSTACLES
- If obstacle ≪ wavelength → signal passes / bends  
- If obstacle ≈ wavelength → partial blocking / scatter  
- If obstacle ≫ wavelength → strong blocking / shadow
