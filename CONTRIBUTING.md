CONTRIBUTING
---

## Project Goals

- Open-source, printable zine  
- Easy to contribute (no serious design or coding required)  
- Modular pages (edit one page without breaking everything)  
- Expandable (Level 2, regional inserts, translations)  

Before creating something new, check what exists — improving is often better than duplicating.

---

## Philosophy

- Practical > theoretical  
- Short > complete
- Fixable > perfect

If it doesn’t help someone:
- get on the air  
- build good habits  
- find a fox  
- troubleshoot  
- build something  

…it probably doesn’t belong.

Be kind, generous, and honest. This is a project of sharing and can make a big difference to a lot of people. That's bigger than any one of us.

---

## How to Contribute

You can help by:
- correcting unclear wording
- verifying and improving technical accuracy
- making explanations more beginner-friendly
- contributing diagrams or illustrations
- identifying regional or legal caveats (you might be signing up to make regional versions)
- improving repo structure or build workflow
- testing the guide with real beginners

---

## How to Use

1. Browse the `/pages` directory  
2. Each file = one zine page  
3. Submit suggestions via issues
